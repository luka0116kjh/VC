IP 란?

Internet Protocol - 디지털 세계의 배달 시스템

IP는 네트워크에서 데이터를 주고받기 위한 핵심 규약입니다. 모든 인터넷 연결 장치에 고유한 '주소'를 부여하여, 데이터가 어디로 가야 할지 정확히 길을 안내합니다.

IP의 핵심 원리

  • IP 주소: 인터넷에 연결된 모든 장치(스마트폰, 노트북, 서버 등)의 고유 식별 번호입니다.
  • 패킷 전달: 거대한 데이터를 작은 '패킷' 단위로 쪼개어 전송합니다.
  • 라우팅: 수많은 경로 중 가장 빠르고 효율적인 길을 찾아 패킷을 목적지로 보냅니다.
💡 DHCP란 무엇인가요?

DHCP(Dynamic Host Configuration Protocol)는 장치가 네트워크에 접속할 때마다 자동으로 IP 주소를 할당해주는 편리한 시스템입니다.

IPv4 vs IPv6 비교

인터넷의 성장으로 주소가 부족해지면서 새로운 버전이 탄생했습니다.

항목 IPv4 IPv6
주소 길이 32비트 (약 42억 개) 128비트 (무한에 가까움)
표현 방식 192.168.0.1 (10진수) 2001:0db8:... (16진수)
보안 기능 별도 적용 필요 IPsec 기본 내장
라우팅 효율 낮음 높음 (빠른 처리)
