Domain 이란?

인터넷상의 이름표 - 숫자를 문자로 바꾸는 마법

도메인(Domain)은 복잡한 IP 주소(예: 142.250.196.110) 대신 사람이 기억하기 쉬운 문자열(예: google.com)로 만든 인터넷 주소입니다. 집 주소가 위도와 경도 대신 'OO로 OO길'로 불리는 것과 같은 원리입니다.

도메인의 계층 구조

도메인은 오른쪽에서 왼쪽으로 읽으며 계층적으로 구성됩니다.

최상위 도메인(TLD)

도메인의 종류

  • TLD (최상위 도메인): .com (영리), .org (비영리), .kr (대한민국) 등 목적이나 국가를 나타냅니다.
  • 2차 도메인: 구글(google), 네이버(naver) 처럼 사용자가 직접 정하는 고유한 이름입니다.
  • 서브 도메인: mail.naver.com 처럼 하나의 도메인 아래서 서비스를 구분할 때 사용합니다.
