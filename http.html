HTTP 이란?

HyperText Transfer Protocol - 웹의 심장박동

HTTP는 인터넷에서 웹 서버와 웹 브라우저가 서로 데이터를 주고받기 위한 전 세계 공통의 통신 규약입니다. 우리가 웹페이지를 방문하고, 이미지를 불러오고, 파일을 다운로드하는 모든 과정이 바로 HTTP 인터랙션입니다.

HTTP의 2대 핵심 원리

  • 클라이언트-서버 모델: 브라우저(클라이언트)가 질문(요청)을 던지면, 서버가 답변(응답)을 주는 수직적 구조입니다.
  • 무상태성(Stateless): 각 요청은 이전의 기록을 기억하지 않는 독립적인 사건입니다. 마치 매번 처음 만나는 사람처럼 통신하여 서버의 부담을 줄입니다.

요청(Request)의 구성

클라이언트가 서버에 무엇을 원하는지 상세히 적은 편지와 같습니다.

  • 요청 라인: 무엇을(URL), 어떻게(GET/POST/PUT), 어떤 버전으로 요청할지 명시합니다.
  • 헤더: 브라우저 정보, 허용되는 파일 형식 등 메타데이터를 담습니다.
  • 본문(Body): 로그인 정보나 게시글 같은 실제 전송 데이터를 포함합니다.

응답(Response)의 구성

서버가 요청을 처리한 결과를 담아 보내는 답장입니다.

  • 상태 라인: 성공(200), 실패(404), 오류(500) 등의 상태 코드와 메시지입니다.
  • 본문(Body): 우리가 실제로 보게 되는 HTML 코드, 이미지 데이터, JSON 등이 담겨 있습니다.
