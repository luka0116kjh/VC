Web Core Concepts

웹 개발의 기반이 되는 5가지 핵심 인터넷 서비스와 프로토콜을 한눈에 마스터하세요.

🚀

HTTP

어떻게 웹 브라우저와 서버가 대화할까요? 웹 통신의 표준인 HTTP 프로토콜의 모든 것.

 📍

IP

디지털 세계의 주소, IP. 장치를 식별하고 데이터를 정확한 목적지로 배달하는 원리.

 🏠

Hosting

내 사이트를 전 세계에 공개하는 방법. 서버 공간을 임대하고 운영하는 호스팅의 이해.

 🏷️

Domain

어려운 IP 주소 대신 외우기 쉬운 이름으로. 인터넷 주소 창의 핵심, 도메인 네임.

 🧭

DNS

도메인 이름을 IP로 바꿔주는 전화번호부. 인터넷의 내비게이션, DNS 시스템의 마법.
