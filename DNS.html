DNS 란?

Domain Name System - 인터넷의 거대한 전화번호부

DNS는 사람이 읽을 수 있는 도메인 이름(예: www.google.com)을 컴퓨터가 이해할 수 있는 IP 주소(예: 142.250.196.110)로 변환해주는 시스템입니다. 우리가 브라우저에 주소를 입력하면, DNS가 실제 서버의 위치를 찾아 연결해주는 '내비게이션' 역할을 수행합니다.

DNS 작동 원리 (8단계)

주소를 입력하고 페이지가 뜨기까지, DNS는 보이지 않는 곳에서 복잡한 과정을 거칩니다.

1

도메인 입력

사용자가 브라우저 주소창에 www.example.com을 입력합니다.

2

로컬 캐시 확인

브라우저와 OS가 이미 알고 있는 주소인지 먼저 확인합니다.

3

재귀 DNS 서버 질의

캐시에 없으면 ISP의 재귀 DNS 서버에 도움을 요청합니다.

4

루트 네임서버

".com" 같은 최상위 정보를 어디서 찾을지 안내받습니다.

5

TLD 네임서버

"example.com"의 관리 서버 주소를 전달받습니다.

6

권한 네임서버

최종적으로 "www.example.com"의 정확한 IP 주소를 획득합니다.

7

IP 주소 전달

찾아낸 IP 주소를 사용자 브라우저에 전달합니다.

8

웹 서버 접속

드디어 브라우저가 해당 IP로 직접 데이터를 요청합니다.
